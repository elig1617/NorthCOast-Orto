# Northcoast Orthopedic Sales

2026 website redesign for [northcoastorthopedics.com](https://www.northcoastorthopedics.com/).

The business, services, catalogs, and government vehicles stay the same. Contact, ownership, and credential fields are placeholders until confirmed.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
```
